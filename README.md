# Becal-touring-System
Sistema de Gestión y Visibilidad para el Sector Turístico de Calkiní (con enfoque en los tejedores) Diseño y desarrollo de una plataforma digital integral que permita a los artesanos tejedores de jipi de Becal, así como a otros prestadores de servicios turísticos locales, gestionar, visibilizar y comercializar su oferta cultural y turística.
